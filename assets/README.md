# Artwork

`fleab.svg` is the documentation logo, based on the project author's supplied
`Fleab-smoothed-outline.svg`. It remains a vector image with its original
1254 × 1254 viewBox and transparent background.

The supplied file contained 596 paths and 492,551 characters of path coordinates.
SVGO 4.1.0 removes export overhead, shortens path commands and rounds coordinates
to one decimal place. The optimized SVG is 178,883 bytes, down from 531,800 bytes
(66.4% smaller). Source and optimized renders were compared at 180, 512 and 1254
pixels on light and dark backgrounds, and visually inspected at 512 pixels.
Coordinate rounding is approximate; the artwork is preserved at README sizes.

To repeat the optimization from the original supplied file:

```sh
npx --yes svgo@4.1.0 --config tools/svgo.config.mjs \
  --input /path/to/Fleab-smoothed-outline.svg --output assets/fleab.svg
```

The existing `fleab.png`, `fleab.ico` and `fleab.icns` are the separate desktop
icon assets generated by `tools/render-icon.ps1`. Updating the README logo does
not regenerate the application icon family.
